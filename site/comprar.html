Como obter o Sistema

O APK é gratuito para descarregar. Para jogar, precisas de um código de ativação, que compras diretamente ao criador.

  1. Descarrega o APK oficial

    Só deste site. Instala-o no teu Android. O jogo abre no ecrã de ativação.

  2. Fala connosco no WhatsApp

    Diz que queres o código de ativação. A mensagem que o jogo prepara já leva o código do teu aparelho.

  3. Paga por Multicaixa Express

    Recebes os dados para a transferência. Nunca te pedimos o PIN nem códigos do banco.

  4. Introduz o código e joga

    Recebes um código como este, escreves-o no jogo e a tua conta fica marcada como Jogador legalizado.

Só o Sistema oficial é legal

Cada código de ativação é pessoal e ativa um só aparelho. Cópias não oficiais do APK, códigos partilhados, revendidos ou obtidos sem pagamento levam ao bloqueio permanente do aparelho. Desinstalar e instalar outra vez não desbloqueia.

Se achas que foste bloqueado por engano, contacta-nos pelo WhatsApp com o código do aparelho que aparece no jogo. Cada caso é revisto.

Perguntas

Preciso de internet para jogar?

Só para ativar o jogo, sincronizar a conta e jogar com amigos. As missões e os combates funcionam sem internet. De vez em quando o jogo pede uma ligação para confirmar que o aparelho continua autorizado.

Como pago?

Por Multicaixa Express. Falas connosco no WhatsApp, recebes os dados para a transferência e, quando o pagamento é confirmado, enviamos o teu código de ativação.

Quanto tempo demora a receber o código?

Assim que o pagamento é confirmado, enviamos o código pelo mesmo WhatsApp.

Posso usar o mesmo código noutro telemóvel?

Não. Cada código ativa um só aparelho. Se mudares de telemóvel, fala connosco: o teu progresso pode ser transferido com o ID de Jogador.

O que quer dizer «Jogador legalizado»?

É a marca que aparece no teu perfil e para os teus amigos quando ativaste o jogo com um código oficial. Quem também comprou Cristais aparece como Premium legalizado.

Há compras dentro do jogo?

São opcionais. Os Cristais abrem as arenas do Coliseu e itens exclusivos, mas todo o caminho dos 10 portões se faz sem gastar nada além da ativação.

Funciona no iPhone?

Ainda não. O Sistema está disponível para Android 6 ou superior.
